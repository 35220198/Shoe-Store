# StepUp Shoe Store

**Description:** Modern responsive shoe store built with HTML, CSS and JavaScript. Features an animated colour-changing hero, product grid and a working shopping cart with quantities, totals and saved items. Fits phones, tablets and desktops. No dependencies.

## Files
All files go in ONE folder (no subfolders):
- `index.html`, `style.css`, `script.js`

## Run (PowerShell)
```powershell
cd "C:\Users\-admin\Desktop\shoe-store"
python -m http.server 8000
```
Open http://localhost:8000 (press Ctrl + F5 after changes).
